Privacy Policy

Insane Moments Daily · Last updated: October 22, 2026

This policy explains how the Insane Moments Daily uploader ("the App") handles data. The App is a private tool used only by the owner of the YouTube channel @InsaneMomentsDailyHQ to upload short videos to that channel.

1. Information We Collect

  • OAuth tokens: when the channel owner signs in with Google, the App receives an access token and refresh token for the YouTube Data API. They are used only to upload videos and read basic channel information.
  • Media content: the App processes publicly available videos released under the Creative Commons Attribution (CC BY) license to create short clips.

The App does not collect personal data from viewers or from any other user.

2. How We Use Data

Google user data is used only to upload clips, set their title, description and privacy status, and confirm which channel is connected. It is never sold, shared, or used for advertising.

3. Third-Party Services

The App uses the YouTube API Services. By using it you also agree to the YouTube Terms of Service and the Google Privacy Policy. The App's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

4. Data Storage and Security

OAuth tokens are stored only on the channel owner's own computer in a local configuration file and are never sent to any server we operate. Downloaded source videos are deleted automatically after processing.

5. Revoking Access

Access can be revoked at any time from Google Account permissions.

6. Contact

Questions about this policy: babycreativ@gmail.com
